## stucture
**student.py**:封装了一个学生的所有信息
**team.py**:一个学生的列表,同时附加一些计算组内的基本信息

**main.py**程序的门户,声明一个“simulator”实例,调用它对数据进行处理. main本身没有做任何事
**simulator.py**包括整个程序的主要顺序,从文件读入,分组到输出
**team_allocator.py**负责核心算法
